# 追更簿（HarmonyOS NEXT）

一个本地优先的视频追更与进度记录应用，面向哔哩哔哩、腾讯视频、爱奇艺、优酷和芒果 TV。

## 已完成的首版范围

- 添加视频链接、平台、标题、集数及精确到秒的观看进度
- 自动从链接识别受支持平台（也允许手动选择）
- 本机持久化保存；重新打开应用后仍保留内容
- 最近观看优先、可切换“在追 / 已看完”筛选
- 每个条目均保存最后更新日期和备注

## 关于“自动读取平台进度”

首版将精确进度作为用户可编辑数据保存，不采集平台账号凭据，也不绕过登录或抓取私密观看记录。不同平台的观看进度通常属于其账号数据，只有在平台提供面向第三方的正式授权 API 后，才能在用户授权下可靠同步。

数据模型已经为后续接入预留 `platformVideoId` 和 `syncMode` 字段。届时每个平台以独立适配器实现，保证一项接入失效不影响本地进度记录。

## 在 DevEco Studio 中运行

1. 用 DevEco Studio 打开本目录。
2. 为项目选择已安装的 HarmonyOS SDK，并按 IDE 提示补全项目级签名配置。
3. 运行 `entry` 模块到手机或模拟器。

这个项目采用 ArkTS/ArkUI Stage 模型，进度数据以 `@ohos.data.preferences` 保存在应用沙箱中。对于大量历史记录，下一步可无缝切换至 RDB（关系型数据库）。

## 后续优先项

1. 从系统分享菜单接收视频链接。
2. 一键在对应平台打开链接。
3. 导出/导入和云端备份。
4. 在平台具备公开授权能力时，添加该平台的官方同步适配器。
